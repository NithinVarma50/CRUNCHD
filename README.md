
# CRUNCHD 🍔

**Street Food Café UI Concept**

CRUNCHD is a **UI and frontend concept project** for a street food café.
This project was built purely for **design and frontend exploration** in free time and does **not represent a real brand or café**.

The focus is on **layout structure, visual hierarchy, and component-based frontend architecture**, using a poster-style, scroll-driven UI approach.

🔗 **Live Demo:** [https://crunchd.vercel.app/](https://crunchd.vercel.app/)

---

## 🧠 About the Project

This project explores:

* Bold visual layouts
* Poster-style sectioning instead of traditional page structure
* Responsive, mobile-first UI
* Clean and modern frontend setup

All content displayed on the website (menu items, text, reviews, etc.) is **mock data** created solely for demonstration purposes.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+ recommended)
* npm or pnpm

### Installation

```bash
git clone https://github.com/your-username/crunchd.git
cd crunchd
npm install
```

### Run Locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.
